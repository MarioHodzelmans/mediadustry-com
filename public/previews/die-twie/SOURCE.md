# Gastrobar Die Twie — websitevoorbeeld

Standalone responsive concept snapshot for the Die Twie quotation. The concept uses publicly visible business copy, opening hours, address and contact details from https://www.dietwie.nl/ as reviewed on 2026-10-09. Existing public imagery is referenced from that website and is not copied into this repository. Confirm text, current hours, menu and image permissions with the client before any production launch.
