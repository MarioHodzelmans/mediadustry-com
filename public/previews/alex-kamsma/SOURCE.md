# Alex Kamsma website preview

Standalone snapshot rendered from the user-owned sibling repository `mediadustry-customer-alex-kamsma-design-parket`, homepage source at commit `9ffd927`. The full original homepage content and anchor navigation are preserved. Images are local WebP encodings of the verified original JPEG/PNG files; fonts are losslessly converted from that repository to WOFF2, with every original glyph retained. Images use at most 1280 pixels of width and WebP quality 65–75; below-fold images use native lazy loading and low fetch priority. A small accessible mobile navigation toggle is added only in this preview. No tracking, form submission or framework runtime is included. The surrounding proposal identifies this as a preview; it is not a claim that the live external website is controlled by the parent page.
